# If

“If” is an ending: **-са/-се** on the verb, then a short personal ending, the same as in the [past tense](learn:past) (-м, -ң, -ңыз, nothing, -қ):

- Уақытым болса, келемін. If I have time, I'll come.
- Ақша болса, сатып аламын. If there's money, I'll buy it.
- Сен барсаң, мен де барамын. If you go, I'll go too.

::forms conditional бару келу болу айту

## If not

Put **-ма/-ме** before -са: бармасам (if I don't go), келмесе (if he doesn't come).

::drill conditional
