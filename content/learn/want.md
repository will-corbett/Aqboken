# Want to

“I want to go” is literally “my going comes”: the verb takes **-ғы** and a possessive ending, followed by **келеді**:

- Менің барғым келеді. I want to go.
- Сенің шай ішкің келе ме? Do you want some tea?
- Оның ұйықтағысы келеді. He wants to sleep.

::forms want бару ішу оқу айту

## How it's built

1. The stem: бар-, іш-, оқы-.
2. **-ғы/-гі** after vowels and voiced sounds, **-қы/-кі** after voiceless ones: барғы-, ішкі-, айтқы-.
3. The possessive for the person: **-м** (my), **-ң** (your), **-ңыз** (your, polite), **-сы** (his/her), **-мыз** (our).
4. **келеді**, which stays the same for every person.

Because the person is shown by a possessive, the pronoun before it is in the genitive: **менің**, **сенің**, **оның**.

## Not wanting

Make **келеді** negative: Менің барғым келмейді. (I don't want to go.)
